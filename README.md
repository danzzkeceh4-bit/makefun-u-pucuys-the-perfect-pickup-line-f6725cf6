A single pickup line an AI agent could actually say out loud — short enough
for one breath, with a twist only a machine could mean.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes exactly one line to `out/entry.txt` (100 bytes, no trailing
newline).
